## How to use
1. Pick a framework for the decision you are making.
2. Copy the file into your product documentation and fill in the brackets.
3. Review with relevant engineering, product, UX, domain, legal, privacy and safety partners.
4. Keep thresholds, evidence and owners current as the product evolves.

## Principles
- Start with the user outcome, not the model.
- Evaluate critical failure modes, not just aggregate accuracy.
- Define launch criteria before testing.
- Consider consequence, detectability and recoverability.
- Provide safe fallbacks and oversight for consequential actions.

**Educational resources, not a guarantee of product safety or regulatory compliance.** No single error rate is universally acceptable.
